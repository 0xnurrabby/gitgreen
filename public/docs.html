Getting started

Clone the repository and run it with npm start. The server listens on PORT (default 8080).

Configuration

All options are environment variables:

  • PORT - server port
  • HOST - bind address
  • VERBOSE - enable verbose logging
  • DATA_DIR - where state is stored

API

  • GET /api/stats - runtime statistics
  • GET /api/health - health check
  • GET /api/items - list items
  • POST /api/items - create an item
