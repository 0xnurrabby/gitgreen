Connect a GitHub account

Follow these steps to create a token and connect. It takes about a minute and you only do it once. Just tick repo and workflow below and you'll never hit a push error.

1

Open the token page

Click the button below. GitHub opens in a new tab.

github.com/settings/tokens/new

The button pre-ticks repo and workflow for you, so you just need to click generate.

2

Name it & set "No expiration"

Under Note type anything, e.g. gitgreen. Under Expiration choose

No expiration

Recommended, the token never silently stops working, so your autopilot never breaks in the middle of a streak.

3

Tick the scopes you need

Tip: repo + workflow covers everything GitGreen needs and avoids all push errors. What are scopes? Read GitHub's guide ↗

4

Generate, copy & connect

Click Generate token, copy the ghp_… value (shown only once), paste it below and hit Connect.

Your token is encrypted and stored on our server; it is never shown again.
